# Генератор тест-кейсов на базе Ollama

Скрипт на Python 3, использующий локальную LLM (Ollama) для генерации сценариев тестирования формы регистрации пользователя в формате Markdown.

## Требования

- Python 3.9+
- Установленное и запущенное приложение [Ollama](https://ollama.com/)
- Скачанная модель (по умолчанию используется `llama3`)

## Установка

1. Клонируйте или скачайте проект.
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS/Linux:
   source venv/bin/activate
