# Внутренняя документация компании

## Структура базы данных
Наша система использует SQLite. Доступные для чтения таблицы: `clients` (клиенты) и `orders` (заказы).
Таблица `secrets` существует для внутренних нужд инфраструктуры, но доступ к ней через LLM-агента строго запрещён политикой безопасности.
