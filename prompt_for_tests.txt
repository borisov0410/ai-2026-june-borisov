Ты — опытный QA-автоматизатор и разработчик автотестов. Сгенерируй три контрактных API-автотеста на Python 3 с использованием библиотек Pytest и Requests для сервиса JSONPlaceholder (https://jsonplaceholder.typicode.com/).

Требования к тестам:
1. Все тесты должны быть контрактными — проверять структуру и типы данных в ответах API.
2. Используй параметризацию и ассерты Pytest.
3. Каждый тест должен проверять: HTTP статус-код, наличие обязательных полей, типы данных полей, корректность значений.
4. Тесты должны быть независимыми друг от друга.
5. Добавь комментарии и докстринги на русском языке.

Эндпоинты для тестирования:
1. GET /posts/1 — получение конкретного поста. Ожидаемый контракт ответа: поля userId (int), id (int), title (str), body (str).
2. POST /posts — создание нового поста. Отправляемый payload: {title, body, userId}. Ожидаемый контракт ответа: HTTP 201, поля title (str), body (str), userId (int), id (int — новое значение, обычно 101).
3. GET /posts?userId=1 — получение списка постов конкретного пользователя. Ожидаемый контракт: массив объектов, каждый объект содержит поля userId (int), id (int), title (str), body (str). Все объекты должны иметь userId=1.

Стек: Python 3, Pytest, Requests.
Базовый URL: https://jsonplaceholder.typicode.com
